# LandUs

Landing page de LandUs, estudio digital especializado en landing pages personalizadas para emprendimientos y negocios en crecimiento.

## Desarrollo

```bash
npm install
npm run dev
```

## Sanity

El contenido se administra en el Studio alojado:

https://landus.sanity.studio

Para ejecutar el Studio localmente:

```bash
cd studio
npm install
npm run dev
```

## Despliegue

Cada push a `main` construye y publica la landing en GitHub Pages mediante `.github/workflows/deploy.yml`.
